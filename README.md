# SiegeXLanding

## Projekti kirjeldus

SiegeXLanding on õppetöö raames loodud veebilehe projekt, mille eesmärk on tutvustada Siege X Showcase üritust kasutajasõbraliku landing page’i kaudu. Veebileht sisaldab infot ürituse programmi, sponsorite, tiimi, Major 2025 sündmuse ja kasutaja sisselogimise vaate kohta.

Projekt põhineb olemasoleval HTML, CSS ja JavaScript lahendusel. Töö käigus korrastatakse projekti struktuuri, parandatakse kasutajakogemust, täiendatakse sisu ning testitakse veebilehe toimimist erinevates vaadetes.

## Probleemipüstitus

Praegune veebileht sisaldab mitut eraldi HTML-lehte, kuid projekt vajab paremat struktuuri, selgemat dokumentatsiooni, ühtsemat disaini ja kontrollitud töövoogu. Ilma projektijuhtimise tööriistadeta on raske jälgida, millised ülesanded on tehtud, millised on töös ja millised vajavad ülevaatust.

## Projekti eesmärk

Projekti eesmärk on muuta SiegeXLanding veebileht terviklikumaks ja paremini hallatavaks front-end projektiks. Lõpptulemuseks peab olema korrastatud landing page, kus kasutaja saab mugavalt liikuda avalehe, programmi, sponsorite, Major 2025 info, About Us ja login lehe vahel.

## Peamised funktsioonid

* Avaleht ürituse tutvustamiseks
* Programmi leht ürituse ajakava jaoks
* Sponsorite leht partnerite kuvamiseks
* About Us leht projekti või tiimi tutvustamiseks
* Major 2025 leht lisainfo jaoks
* Login leht kasutajaliidese prototüübina
* Ühtne navigatsioon kõigi lehtede vahel
* Responsive disain erinevatele ekraanisuurustele

## Projekti ulatus

Projekti käigus ei looda täielikku backend-süsteemi ega päris kasutajakontode andmebaasi. Login leht jääb front-end prototüübiks. Fookus on staatilise veebilehe struktuuril, kujundusel, kasutajakogemusel ja projektijuhtimise töövoo kasutamisel GitHubis.

## Edukriteeriumid

Projekt loetakse edukaks, kui:

* kõik põhilised HTML-lehed on omavahel loogiliselt seotud;
* navigatsioon töötab igal lehel;
* veebileht on visuaalselt ühtne;
* README kirjeldab projekti eesmärki ja ulatust;
* GitHub Project Board sisaldab töövoogu Backlog, Todo, In Progress, In Review ja Done;
* Issues sisaldavad assignee, label, priority, start date, end date ja milestone infot;
* projektis on 3 milestone’i;
* loodud on Gantt diagramm projekti ajakava visualiseerimiseks.
